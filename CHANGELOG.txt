1.0.0
-----
- First public release.
- Configurable shortcuts (keys 1-9) mapping to any field/value.
- Settings dialog, no code editing required.
- Bilingual interface (English / Portuguese).

1.0.1
-----
- Fixed a Bandit-flagged bare except/pass in language detection (i18n.py).

1.0.2
-----
- Fixed 13 Qt6 compatibility warnings (scoped enums for Qt, QDialogButtonBox
  and Qgis; renamed exec_() to exec()).

1.0.3
-----
- Declared QGIS 4 compatibility (qgisMaximumVersion=4.99).

1.1.0
-----
- Shortcuts are no longer limited to the keys 1-9 or to 9 slots: add as many
  as you need, each with any key or combination (e.g. F5, Ctrl+Shift+A),
  chosen in the settings dialog ("Add shortcut" / ✕ buttons).
- Shortcuts are re-registered as soon as settings are saved (no restart needed).
- Warns when two active shortcuts use the same key.
- QAction/QShortcut imported in a Qt5/Qt6-safe way.
- Settings saved by earlier versions keep working.
